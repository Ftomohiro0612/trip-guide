# 楽天施設導線 全施設 coverage 監査（2026-08-25）

## 結論

メモリップの施設 canon 4,704 件をすべて調査対象にし、楽天トラベル観光体験の日本向け商品一覧 17,262 件と照合した。施設名・都道府県・商品詳細の利用場所を段階的に照合し、候補になった 227 施設について個別商品ページの公開状態、プラン、販売価格、予約導線を確認した。

監査時点で施設 identity と利用可能性を確認できた 126 施設を表示対象とした。残る施設は CTA を表示しない。これは楽天に商品が永続的に存在しないという意味ではなく、監査時点で採用条件を満たす証拠を確認できなかったことを表す。

## coverage

| 項目 | 件数 |
| --- | ---: |
| メモリップ施設 canon | 4,704 |
| 取得した楽天の日本向け商品一覧 | 17,262 |
| 名称・地域照合後の候補施設 | 227 |
| 候補の商品ペア | 450 |
| 詳細確認したユニーク商品 | 431 |
| 採用施設 | 126 |
| 候補になったが非採用の施設 | 101 |

施設 canon の SHA-256 と件数を registry に記録し、canon が変わった状態で古い全施設監査をそのまま通さないよう build gate で検証する。

## 採用条件

- 楽天上の `/experiences/<数字>` 個別商品ページであり、検索結果や周辺宿泊施設一覧ではない
- メモリップ施設と、商品名および所在地・利用場所・運営主体の根拠が一致する
- チケット、入場予約、現地体験、乗車・乗船など、その施設へ実際に行く行動につながる
- 商品詳細が公開中かつ利用可能で、正の販売価格を持つプランと予約導線を確認できる
- 複数商品がある場合は、単体入場券など利用まで最も直接的なものを優先する
- 終了年が商品名に残るもの、公開停止、詳細取得不能、別施設・系列施設、施設内テナントだけの一致は採用しない

## CTA 文言

- 通常のチケットは「楽天でお得にチケットを探す」を標準にする
- 現地体験・予約は「楽天でお得な体験予約を探す」など、できる行動が分かる表現にする
- 商品ページ上で割引額、割引率、楽天限定ペア割、ポイント、付帯特典を確認できた場合だけ、その具体的メリットを優先して表示する
- 比較根拠のない「最安」「公式より安い」「公式よりお得」は表示しない

## 非採用の主な理由

- 商品詳細が非公開、販売停止、または過去年の終了商品
- 一覧には残るが商品詳細を取得できず、利用可能性を確認できない
- 施設名の部分一致にとどまり、所在地・利用場所の根拠が不足する
- 商業施設と館内テナント、同名・系列・周辺施設など、別 identity の商品
- 施設を立ち寄り先に含むだけのツアーで、当該施設の利用導線として直接性が弱い
- より直接的な単体券があり、セット券・周遊券・別プランを優先する理由がない

## 実装上の安全策

- 施設 canon は変更せず、`data/rakuten_facility_actions.json` の審査済み対象だけを表示する
- 施設 ID・slug・施設名の3項目が一致しない場合は表示しない
- 楽天の許可済みホストかつ個別商品 URL 以外は検証で拒否する
- URL のクエリ文字列を禁止し、検索 URL・推測 URL・計測・アフィリエイトパラメータを入れない
- `display_through` がある期間限定商品は期限後に表示しない
- 全件監査時の施設件数・canon hash・楽天取得件数・候補件数を registry に保持する
- 公式サイト導線は既存のまま維持する

## 継続運用

楽天商品の公開・在庫・販売期間は変わり得る。新規採用は同じ exact-match 条件で個別確認し、販売終了や identity の不一致を確認した場合は registry から除外する。施設 canon の追加・変更時は coverage gate が fail closed するため、新しい canon を監査して hash を更新する。
