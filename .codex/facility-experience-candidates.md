# 体験候補の粒度・分類・表示ルール

> 作成: 2026-06-12 / Claude Code PM
> 用途: 「この施設で楽しめそうなこと」を生成する際の標準語彙と判定ルール

## 1. 粒度の原則

- 1項目 = **親が当日を想像できる具体的な行動**（動詞止め）
- 「遊具」ではなく「長いすべり台で遊ぶ」。「動物」ではなく「動物にえさやりをする」
- 固有名詞があるほど良い（「クラフト砦の木製大型遊具で遊ぶ」>「大型遊具で遊ぶ」）

## 2. 標準体験語彙（カテゴリ別）

### 体を動かす
長いすべり台で遊ぶ / ローラースライダーを滑る / アスレチックに挑戦する / ターザンロープで遊ぶ / ふわふわドームで跳ねる / 芝生で走り回る / 広場でボール遊びをする / 巨大迷路に挑戦する / トランポリンで跳ぶ

### 水遊び
じゃぶじゃぶ池で水遊びする / 噴水で水遊びする / プールで泳ぐ / 川遊びをする
※ **水遊びとプールは厳密に区別**（recommended_for_tags_rules.md 準拠。pool タグなしの施設に「プールで泳ぐ」は書かない）

### 動物・自然
動物を見る / 動物にさわる / 動物にえさやりをする / 鳥を腕や肩に乗せる / ポニーに乗る / 季節の花を見る / 昆虫や生きものを探す / 自然の中を散策する

### つくる・学ぶ
工作体験をする / ガラス・陶芸などのクラフト体験をする / 科学展示にさわって学ぶ / 実験ショーを見る / 恐竜の展示を見る / 職業体験をする

### 乗る・見る
乗り物に乗る / 観覧車から景色を見る / SLやミニ電車に乗る / ゴーカートに乗る / キャラクターに会う / ショーやイベントを見る / 絶景・夜景を見る / 写真を撮る

### 過ごし方（横断系）
雨の日に室内で過ごす / ベビーカーで散歩する / お弁当を広げる / 半日ゆっくり過ごす / 1日たっぷり遊ぶ / 小さい子と一緒に遊ぶ / 小学生が体を動かして遊ぶ / 親は併設のカフェ・温泉でひと休みする

※ 語彙は固定リストではない。施設固有の体験はこの粒度に合わせて自由に追加してよい（根拠必須）

## 4. 横断系（過ごし方）の判定ルール

| 体験文 | 条件 |
|---|---|
| 雨の日に室内で過ごす | rain_friendly=◎ かつ indoor_outdoor が 屋内 or 両方 |
| 小さい子と一緒に遊ぶ | target_age が 0歳〜/幼児〜 を含む |
| 小学生が体を動かして遊ぶ | target_age に小学生を含む かつ playground/athletic/running いずれか |
| 半日〜1日たっぷり遊ぶ | 大型複合施設（desc に複数エリア・併設施設の記述）のみ。安易に書かない |
| 親は併設の〜でひと休み | desc/sig に併設施設（温泉・カフェ・レストラン等）の明記があるときのみ |
| お弁当を広げる | **持込可否は施設規則** → 公式確認なしでは書かない（芝生広場があっても不可の施設がある） |
| ベビーカーで散歩する | **園路状況の事実が必要** → 公式確認 or desc 明記がないときは書かない |

## 5. 表示ルール

- 表示名: 「この施設で楽しめそうなこと」（継続）
- 形式: ✓付き箇条書き、2カラム（PC）/1カラム（SP）
- 5〜12項目。3項目未満しか根拠がない施設は無理に埋めず、紹介文の増強を優先
- 「〜（要予約）」「〜（開催日は公式サイトで確認）」の注記は許可（事実の断定を避ける手段として推奨）
- 並び: 主役体験 → 副次 → 過ごし方系
