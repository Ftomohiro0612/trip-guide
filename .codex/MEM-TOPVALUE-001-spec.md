## 0. Owner確定方針 (2026-09-17)

> 実ユーザーにトップを見せたところ、最初の反応が「これって施設検索のサイト？」でした。現在もMemorip固有の
> 「探す→行く→記録→子どもの好きが見える→次のおでかけ」という価値より、施設検索がサービス本体として強く
> 認識される状態です。次のProduct優先事項として、トップページの価値伝達を修正してください。検索やSEOを
> 弱めるのではなく、「検索はMemoripの循環への入口」であることが初見で理解できる状態を目標にします。

2026-09-16 Owner確定の恒久ポジショニング(MEM-ACT-001時点で確定・変更なし):
Memoripは「検索サイトに記録を付けたもの」ではなく、**「遊び場を探すことを入口に、記録 → 子どもの好き →
次のおでかけへ循環するサービス」**。**検索機能・SEOを弱める意図はない。**

## 1. 前提 — 循環を伝える要素はすでにある。今回のフィードバックはMEM-ACT-001後に出たものである

PMが `origin/main` @ `57b5dcda`(`app/page.tsx`)をコードで確認した。**この所見はMEM-ACT-001
(2026-09-16 CLOSED)で行われた改修より後**に実ユーザーへ見せて得られたものであり、
MEM-ACT-001で入った以下の要素は**今も存在するが、それでも「検索サイト」という第一印象を変えられなかった**:

- Hero右側 `HeroMemoryCardCluster`(「記録がたまると見える、子どもの『好き』」のスマホ画面モック。
  「画面イメージ・件数や内容はサンプルです」の注記も既にある)
- Hero内の一番目立つボタンが `/try` への **「登録なしで、思い出を1件つくる →」**(検索ボックスより上)
- flexboxの `order-first` により、循環4ステップ(探す→行く→記録→次のおでかけ)の説明セクション
  (`record-value-heading`)が実際には**地図セクションより前・Heroのすぐ次**に描画されている
  (`app/page.tsx` の `PreferenceRankingMiniExample` 付きセクション)
- layoutレベルの `<meta name="description">`(`app/layout.tsx` の `siteDescription`)と
  `SERVICE.tagline`(`lib/config.ts`)は循環価値を正しく記述している

**したがって「循環を説明する要素を新設する」ことは本トラックの主眼ではない。** 既存要素だけでは
初見の第一印象を変えられなかった、という実測結果を踏まえ、**最初の数秒で目に入るテキスト**を直す。

### 1-1. 残っている本丸: Hero最上部のテキストが100%検索framingである

`app/page.tsx` の Hero(ユーザーが最初に見る領域)を確認すると:

- 最上部バッジ: `無料で遊び場検索｜全国{N}都道府県・{N}施設掲載中` — 「検索」のみ、循環への言及ゼロ
- `<h1>`: `子どもと行ける場所を、近くから探す。` — 「探す」のみ、記録・好き・循環への言及ゼロ
- `<h1>` 直後の説明文には「行った場所を記録すると、子どもの"好き"も少しずつ見えてきます。」と循環への
  言及が**1文だけ**ある。しかし直前の巨大な badge + `<h1>` の視覚的重みに対して、この1文は本文サイズの
  地の文であり、初見のスキャンで負ける位置・weightにある。

**結論**: 循環を"どこかに書く"ことはすでに達成済み。**最初に目に入る2要素(badge / h1)自体が
検索単体の宣言文になっている**ことが、実ユーザーが「検索サイト」と読み取る主因である可能性が高い。
本トラックはここを直す。

## 2. 直すこと

**達成すべき状態**: 未ログイン・スマホ相当(390×844)で、**スクロールなしの最初の画面内**に、
「検索は入口で、その先に記録→好きが見える循環がある」ことを示す言葉が、既存の検索訴求
(バッジの件数訴求・`<h1>`・検索ボックス・現在地/雨/無料等のクイックリンク)と**同等以上の視覚的重みで**
存在すること。

**実装方式はCodex相当(本セッション)が所有する。** 参考の当たり方(強制ではない):

- バッジ文言・`<h1>` 自体、または `<h1>` 直下の一文の書体サイズ/太さ/色を、循環を明示する言い回しへ
  調整する(例: 「探す→記録→好きが見える」を検索訴求と並列に見せる、バッジをもう1本追加する、等)。
  **具体的なコピー・レイアウトの最終決定はCodex相当が行ってよい**が、AC-1〜AC-3を満たすこと。
- `HeroMemoryCardCluster` の見出し文言(「記録がたまると見える、子どもの『好き』」)は、
  それ単体では「これがMemoripの本体機能」であることが伝わり切らない可能性がある。バッジ/`<h1>`側の
  修正で足りない場合はここも調整してよい。

**禁止(既存の恒久制約を継続)**:
- 検索導線(検索ボックス・現在地・テーマ・カテゴリ・47都道府県リンク・おすすめ施設)の削除・
  件数表示の削減・内部リンクの削減。
- SEOを弱めること。`<title>` / meta description / 構造化データ / 内部リンク数 / sitemap URL数を
  現状(`57b5dcda`)以上に保つこと。
- `<h1>` からキーワード「探す」「遊び場」「近く」等の検索文脈を完全に除去すること
  (検索の入口性を薄めるため禁止。**両立**が目標)。
