# recommended_for_tags タグ付けルール

> 確定: 2026-06-10

## 使用するキー（19個）

以下のキーのみ使用する。reaction_tags.id の正本に準拠。

| キー | 使いどころ |
|---|---|
| `animal` | 動物系施設全般 |
| `animal_contact` | ふれあい・体感要素が明確な施設 |
| `animal_feed` | エサやりが施設の体験として明確な場合のみ |
| `water_play` | じゃぶじゃぶ池・水遊び場・噴水・親水広場など「浅い水遊び・水に触れて遊ぶ」施設。泳げるプール系には使わない |
| `pool` | 市民プール・屋外プール・屋内プール・温水プール・流れるプール・幼児用プールなど「泳ぐ・入水する前提」の施設 |
| `playground` | 遊具全般（公園・屋内遊び場等） |
| `athletic` | 登る・渡る・フォレストアドベンチャー・トランポリン等、挑戦系アスレチック要素が明確な施設 |
| `slide` | 長いすべり台・大型すべり台が施設の特徴として明確な場合のみ |
| `running` | 走り回ることが施設の主な価値として明確な場合のみ |
| `wide_space` | 広さ・開放感が施設の価値として明確な場合のみ |
| `vehicle` | 乗り物体験がある施設（SL・ゴーカート・ロープウェイ等） |
| `craft` | 工作・ものづくり・陶芸等の体験施設 |
| `experience` | 農業・食育・収穫体験等の体験施設 |
| `exhibition` | 博物館・科学館・美術館・水族館・キャラクター施設・模型/ホビー系 |
| `science` | 科学・実験・プラネタリウム系 |
| `dinosaur` | 恐竜展示がある施設 |
| `character` | キャラクターテーマの施設 |
| `nature` | 自然・森・海・川が施設の主な価値として明確な場合 |
| `food` | 食べ物体験・味覚狩り等 |

## 使用しないキー（6個）

以下は施設の特性ではなく、訪問後の子どもの反応・成長ログとして visit_child_tags で活用する。

| キー | 理由 |
|---|---|
| `brave_challenge` | 「怖がらず挑戦した」は子どもの成長記録。施設特性は `athletic` で表現 |
| `played_with_friends` | 訪問時の社会体験記録 |
| `played_with_siblings` | 訪問時の社会体験記録 |
| `first_time` | 訪問時の成長記録 |
| `did_alone` | 訪問時の成長記録 |
| `other` | 汎用すぎる |

## タグ付けの数・スタイル

- 1施設あたり **2〜4個**、最大5個
- タグを絞ることで施設の特徴が明確になる
- 迷ったら少なめに（あとで追加できる）

## 使い分けの補足

- `playground` vs `athletic`：遊具があるだけなら `playground`。登る・渡る・高所など明確なアスレチック要素があれば `athletic` を追加
- `playground` vs `running`：走り回れることが主な価値（広い芝生・野原等）のみ `running`。遊具がメインなら `playground`
- `wide_space` は広さが施設の売りとして明確な場合のみ。公園なら大体広いので機械的に付けない
- `animal_feed` は「エサやり体験」が明示されている施設のみ。動物がいるだけでは付けない

## water_play / pool 付与の厳格ルール（2026-06-10 確定）

### 共通
- `summer_water_play=◎/○` は **water_play / pool タグ付与の根拠にしない**
  - `needs_web_check: true` + `web_check_reason` に「summer_water_play はあるが、水遊び設備の明記確認が必要」を記載するのみ
- タグ判定のキーワード検索は `description` / `signature_experiences` / `USP` / `tags` のみ使用し、**施設名（name）は含めない**

### water_play の付与キーワード（浅い水遊び系）
- `じゃぶじゃぶ` `水遊び場` `噴水` `親水` `水辺遊び` `水上遊具` `川遊び` `海水浴` `水あそび`
- 自然系（川遊び / 海水浴 / 親水）で付与する場合は必ず `needs_web_check: true`
- **「プール」は water_play の根拠にしない（pool を使う）**

### pool の付与キーワード（泳げるプール系）
- `プール` `温水プール` `流れるプール` `幼児用プール` `スライダー`
- 施設名に「プール」が含まれる場合は `pool` 候補 + 必ず `needs_web_check: true`
  - web_check_reason: 「施設名にプールとあるため pool 候補。ただし説明文・summer_water_play では設備詳細を確認できないため」
- description に「プール」が明記されている場合は `pool` 確定、`needs_web_check` は任意

## confident 基準

| confidence | 基準 |
|---|---|
| `high` | カテゴリ・施設名・年齢範囲から迷いなくタグが決まる |
| `medium` | 情報不足や判断が難しいが、おおむね妥当 |
| `low` | 施設情報が少なく、タグの根拠が薄い |

`needs_human_review: true` は `low` の場合は必須。`medium` で特に判断が難しい場合も true にする。
