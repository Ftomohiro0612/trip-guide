## やること（確定スコープ）

### 1. 固定IDリストを持たせる

- `lib/config.ts` に追加（単一の出どころ）:
  ```ts
  // トップ「おすすめ施設」の固定キュレーション（自動抽出をやめ、子どものタイプ別バランスで手選び）
  // 並び順は表示順。exclude_candidate 等で非表示の施設は visibleFacilities 側で自動除外され、
  // 見つからなければスキップする（page.tsx 側で実装）。
  export const FEATURED_FACILITY_IDS: number[] = [801, 675, 245, 782, 518, 136];
  ```
- ID対応（オーナー確定・**変更しない**）:
  | id | 施設 | タイプ |
  |---|---|---|
  | 801 | 長井海の手公園 ソレイユの丘（神奈川） | 大型外遊び・動物 |
  | 675 | ふなばしアンデルセン公園（千葉） | 遊具・アスレチック |
  | 245 | 国営昭和記念公園（東京） | 広い・自然 |
  | 782 | こどもの国（横浜・神奈川） | 大型外遊び・広い |
  | 518 | 国営武蔵丘陵森林公園（埼玉） | 自然・広い |
  | 136 | 山梨県立科学館（山梨） | 屋内・雨の日・学び |
  - **注意**: 「こどもの国」は同名が複数あるため必ず **id=782（横浜）**。id=22 富士山こどもの国 等と取り違えない。

### 2. page.tsx の featured を固定リスト参照に置換

- `app/page.tsx:933-935` を以下の趣旨に置換:
  ```ts
  const featured = FEATURED_FACILITY_IDS
    .map((id) => visibleFacilities.find((f) => f.id === id))
    .filter((f): f is Facility => Boolean(f));
  ```
  - `visibleFacilities` は exclude_candidate 等を既に除外済みなので、その中を探すことで**非表示施設は自動除外**。
  - **見つからない id はスキップ**（filter で除去）。`.slice(0,6)` は不要（リストが定義順）。
  - `Facility` 型・`FEATURED_FACILITY_IDS` の import を追加。
  - 描画箇所 `featured.map(...)`（1161行）は無変更でよい。

### 3. 見出しの変更（app/page.tsx:1147-1150）

- h2（id="featured-heading"）の文言「ピックアップ」→ **「子どもの"好き"が見つかるおすすめ施設」**（オーナー確定）。
- 小見出し（直下の `<p>`）「雨の日OK・無料で遊べるおすすめ施設」→ 内容と整合する短い説明に置換。推奨:**「大型公園・自然・科学館など、子どものタイプ別に選んだ定番スポット」**（事実整合の範囲。創作しすぎない。長ければ簡潔化可）。
- 右側の「一覧を見る」等の Link（1153-1158）は無変更。
