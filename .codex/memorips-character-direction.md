# メモリップ キャラクター方針（オーナー確定方向 + ラフ3案）

> 作成: 2026-06-12 / オーナー方針の記録（Claude Code PM 転記）
> 状態: **案1（芽が出た地図ピンの案内キャラ）で確定**（2026-06-12 オーナー選定）。次は試し配置案の作成

## 方針

- メインブランドは現状維持。キャラクターは**補助的に使う**
- 世界観: 「親しみ」「記録」「成長」「地図」「好きが見える」
- 「子どもそのものを前面に出すマスコット」ではなく「**ブランドモチーフの小さな案内キャラ**」
- 幼すぎ・漫画っぽすぎ・主張が強すぎるものは避ける（親向けの安心感を優先）

## 使う場所（補助配置から開始）

1. 使い方セクション / 2. 記録ゼロの空状態画面 / 3. 記録完了後の振り返りカード / 4. 登録導線まわり / 5. LP・お知らせ・SNS素材

**置かない場所**: 法務ページ / 施設詳細の主要情報 / 地図の主役部分 / 検索UI中心部

## ラフ3案

### 案1: 芽が出た地図ピンの案内キャラ
- コンセプト: 「おでかけの記録が、未来の地図になる」
- モチーフ: 地図ピン + 芽 + 足あと/きらめき
- 印象: ロゴ親和性が最も高い。親しみがあるが幼すぎない
- 用途: 使い方セクション・空状態UI・ガイド吹き出し・LP/SNS案内役
- 一言: メモリップの世界観をそのままキャラ化した案

### 案2: 親子の足あとをたどる小さなナビキャラ
- コンセプト: 「親子で歩いたおでかけが、思い出として積み重なる」
- モチーフ: 親の足あと + 子どもの足あと + 地図ルート
- 印象: 親子感・ストーリー性が強い
- 用途: オンボーディング・記録完了時・成長セクション・振り返り導線
- 注意: 足あとだけだと抽象的。キャラ性の補強が必要
- 一言: 親子のおでかけの積み重ねを象徴する案

### 案3: 記録ノート・カードの精霊キャラ
- コンセプト: 「記録すると、"うちの子の好き"が育って見えてくる」
- モチーフ: 記録カード + ノート + 星/きらめき + 成長メーター風要素
- 印象: 記録サービスらしさが強く、機能説明と相性が良い
- 用途: 記録導線・写真機能・振り返りカード・好きTOP3/分析UI
- 注意: プロダクト寄りになるため温かみをデザインで補う
- 一言: 記録そのものを楽しく見せる案

## 採用理由（2026-06-12 オーナー）

- メモリップのロゴ・Spark Atlas の世界観と最も相性が良い
- 「地図」「記録」「成長」「発見」が自然に表現できる
- 子ども本人をキャラクター化しないので、年齢・性別を固定せず使いやすい
- 親向けサービスとしての安心感を損なわず、かわいさを足せる
- トップ・空状態UI・記録完了後カード・オンボーディング・LP・SNS素材に展開しやすい

## 基本コンセプト

| 項目 | 内容 |
|---|---|
| 名前 | 仮称「**ピプ**」（pin + sprout。確定はオーナー判断、SNS展開前までに決定） |
| モチーフ | 地図ピン + 芽 + 足あと/きらめき |
| 役割 | メモリップの**小さな案内役**（主役ではない。ユーザーの記録と家族が主役） |
| トーン | かわいいが幼すぎない。親向けに安心感がある。説明役としても単体でも成立 |
| 立ち位置 | 補助キャラ。既存ロゴ・トップデザインとぶつからない大きさ・頻度で使う |

## 利用シーン別 配置案（SVG/画像制作前のラフ）

### シーン1: トップページ 使い方セクション
- 配置: 3ステップ説明（さがす→でかける→きろくする）の最終ステップ脇、または セクション見出しの右側に小さく1体
- サイズ: 48〜64px 程度。ステップアイコンより目立たないこと
- ポーズ: 案内（片手で次のステップを指す）
- コピー例: 吹き出しなし（トップは詰め込まない）。キャラは視線誘導のみ

### シーン2: 記録がまだない空状態（/mypage/visits・/mypage/wishlist 0件時）
- 配置: 空状態メッセージの上に中サイズで1体（このシーンだけはキャラが主役でよい）
- サイズ: 96〜120px
- ポーズ: 首かしげ or 芽がまだ小さい状態（「これから育つ」メタファー）
- コピー例: 「まだ記録がないよ。最初のおでかけを記録してみよう！」/ wishlist:「気になる施設を♡で保存できるよ」
- CTA ボタンとセットで配置（記録する / 施設をさがす）

### シーン3: 記録完了後の振り返りカード
- 配置: 保存完了カードの右上 or コーナーに小さく
- サイズ: 40〜56px
- ポーズ: よろこび（きらめき付き）。記録件数の節目（1件目・10件目等）では芽が少し育った差分を出すと「成長」が表現できる（将来拡張）
- コピー例: 「きろくが増えたよ！」（短く、毎回は出しすぎない）

### シーン4: 登録導線（/auth/register 周辺・未ログイン時の誘導）
- 配置: 登録フォームの上部見出し脇、または未ログインで記録ボタンを押したときの案内モーダル
- サイズ: 56〜72px
- ポーズ: お辞儀 or 手を振る（welcome）
- コピー例: 「無料ではじめられるよ」
- 注意: フォーム入力の邪魔をしない。同意文言（規約リンク）の近くには置かない（法務領域とトーンを混ぜない）

### 置かない場所（再確認）
法務ページ（/terms・/privacy）/ 施設詳細の主要情報 / 地図の主役部分 / 検索UIの中心部

## SVG/画像制作に進む前の仕様案

- **第一弾は SVG**（コード制作・色変更や差分ポーズが容易・軽量）。リッチ版イラストは検証後
- 必要バリエーション（初期4種）: ①通常 ②案内（指差し） ③よろこび（きらめき） ④空状態（首かしげ）
- ファイル形式: SVG コンポーネント（`components/character/` 配下、props でバリエーション切替）
- サイズ展開: 40px〜120px で破綻しないシンプルな造形（細部を描き込みすぎない）
- アクセシビリティ: 装飾扱い（aria-hidden）。意味を持たせる場合は alt 相当のラベルを付ける

## キャラデザイン・ブリーフ（案1）

- ベース: メモリップロゴの地図ピン形状を踏襲した丸みのあるピン
- 頭頂部に双葉の芽。小さな点目 + 微笑み（口は小さく）。頬に薄い赤み可
- カラー: ブランドのグラデーション（sky-400 → cyan-400 → emerald-400）系。芽は emerald
- 禁止: 人間の子どもの顔・キャラ然とした大きな目・強い輪郭線・原色多用
- バリエーション想定: 通常 / 案内（指差し・吹き出し）/ よろこび（きらめき）/ 空状態用（おやすみ・首かしげ）

## 試し配置（第一弾スコープ）

1. **空状態UI**: /mypage/visits（記録0件）と /mypage/wishlist（0件）にキャラ + 一言コピー
2. **トップの使い方セクション**: ステップ説明の脇に小さく配置
- 法務ページ・地図・検索UIには置かない（方針通り）
