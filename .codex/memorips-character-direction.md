# メモリップ キャラクター方針（オーナー確定方向 + ラフ3案）

> 作成: 2026-06-12 / オーナー方針の記録（Claude Code PM 転記）
> 状態: **案1（芽が出た地図ピンの案内キャラ）で確定**（2026-06-12 オーナー選定）。次は試し配置案の作成

## 方針

- メインブランドは現状維持。キャラクターは**補助的に使う**
- 世界観: 「親しみ」「記録」「成長」「地図」「好きが見える」
- 「子どもそのものを前面に出すマスコット」ではなく「**ブランドモチーフの小さな案内キャラ**」
- 幼すぎ・漫画っぽすぎ・主張が強すぎるものは避ける（親向けの安心感を優先）

## 使う場所（補助配置から開始）

1. 使い方セクション / 2. 記録ゼロの空状態画面 / 3. 記録完了後の振り返りカード / 4. 登録導線まわり / 5. LP・お知らせ・SNS素材

**置かない場所**: 法務ページ / 施設詳細の主要情報 / 地図の主役部分 / 検索UI中心部

## ラフ3案

### 案1: 芽が出た地図ピンの案内キャラ
- コンセプト: 「おでかけの記録が、未来の地図になる」
- モチーフ: 地図ピン + 芽 + 足あと/きらめき
- 印象: ロゴ親和性が最も高い。親しみがあるが幼すぎない
- 用途: 使い方セクション・空状態UI・ガイド吹き出し・LP/SNS案内役
- 一言: メモリップの世界観をそのままキャラ化した案

### 案2: 親子の足あとをたどる小さなナビキャラ
- コンセプト: 「親子で歩いたおでかけが、思い出として積み重なる」
- モチーフ: 親の足あと + 子どもの足あと + 地図ルート
- 印象: 親子感・ストーリー性が強い
- 用途: オンボーディング・記録完了時・成長セクション・振り返り導線
- 注意: 足あとだけだと抽象的。キャラ性の補強が必要
- 一言: 親子のおでかけの積み重ねを象徴する案

### 案3: 記録ノート・カードの精霊キャラ
- コンセプト: 「記録すると、"うちの子の好き"が育って見えてくる」
- モチーフ: 記録カード + ノート + 星/きらめき + 成長メーター風要素
- 印象: 記録サービスらしさが強く、機能説明と相性が良い
- 用途: 記録導線・写真機能・振り返りカード・好きTOP3/分析UI
- 注意: プロダクト寄りになるため温かみをデザインで補う
- 一言: 記録そのものを楽しく見せる案

## 次のステップ

3. 検証で手応えがあれば、イラストレーター or 画像生成でリッチ版を作成（ブリーフは下記）

## キャラデザイン・ブリーフ（案1）

- ベース: メモリップロゴの地図ピン形状を踏襲した丸みのあるピン
- 頭頂部に双葉の芽。小さな点目 + 微笑み（口は小さく）。頬に薄い赤み可
- カラー: ブランドのグラデーション（sky-400 → cyan-400 → emerald-400）系。芽は emerald
- 禁止: 人間の子どもの顔・キャラ然とした大きな目・強い輪郭線・原色多用
- バリエーション想定: 通常 / 案内（指差し・吹き出し）/ よろこび（きらめき）/ 空状態用（おやすみ・首かしげ）

## 試し配置（第一弾スコープ）

1. **空状態UI**: /mypage/visits（記録0件）と /mypage/wishlist（0件）にキャラ + 一言コピー
2. **トップの使い方セクション**: ステップ説明の脇に小さく配置
- 法務ページ・地図・検索UIには置かない（方針通り）
