## 目的

微調整ではなく再設計。初見の親が3秒で
「子どもの"好き"が見える、おでかけ記録サービス」+「使うと何が嬉しいか」
を理解できるトップにする。キーワード: 温かさ・親子感・記録の蓄積感・成長が見える。

## Task 1: ヒーロー再設計

### レイアウト（2カラム維持・中身を刷新）

**左カラム（コピー + CTA）**

```
[バッジ] 📍 関東甲信越9県 · 1,000施設超
[h1]    子どもの"好き"が、
        地図になっていく。
[サブ]   遊び場を探して、おでかけして、子どもの反応をワンタップで記録。
        記録がたまるほど「うちの子はこれが好き」が見えてきます。
[CTA主] ✨ 無料で記録をはじめる   → /auth/register
[CTA副] 🗺️ まずは遊び場を探す    → /facilities
[小さく] 登録は無料・記録は30秒で完了
[検索]  コンパクトな検索バー（現状より小さめ。主役は記録訴求）
```

- h1 は現行コピーから変更してよい（上記が第一候補。「子どもの"好き"が見える、おでかけ記録サービス」を h1 直下のサブ見出しか visually-hidden で残し SEO 語句は保持）
- CTA は主従を明確に: 主 = 記録をはじめる（白背景・濃い文字・影）、副 = 探す（アウトライン）
- 既存 `/sign-up` ではなく実在の `/auth/register` に向ける（要確認: 実ルート名を調べて合わせること）

**右カラム（本物っぽい記録UI）**

半透明の抽象カードをやめ、**白背景の「アプリ画面」風カード**にする（スマホ画面の縁取り風、shadow-2xl、rounded-[2rem]）:

```
┌─────────────────────────┐
│ 👧 ゆいちゃん (7歳)        │ ← 子どもアバター円 + 名前
│ ─────────────────────   │
│ 📍 よこはまこどもの国      │ ← 最近の記録カード
│   6月8日 · ☀️             │
│   😊 たのしかった 🔥 また行きたい │ ← 反応タグ（sky-100チップ）
│   ★★★★☆                 │
│ ─────────────────────   │
│ ゆいちゃんの"好き" TOP3    │
│ 1. 🐾 動物      12回      │ ← 横棒グラフ風（emerald系バー）
│ 2. 💧 水遊び     8回      │
│ 3. 🛝 遊具       5回      │
│ ─────────────────────   │
│ 📸 写真もまとめて思い出に   │ ← 写真サムネ風の角丸グレー矩形2つ
└─────────────────────────┘
[カード外に小さく] あなたの家族の記録がここにたまっていきます
```

- 色はサイトトーン（白・slate・sky/emerald）で、ヒーローのグラデーション上に浮く白カード
- カードを 2〜3°傾け（rotate-2）、後ろに2枚目のカードの角を覗かせて「たまっていく」感を出す
- 全て静的JSX（実データ不要）。ただし表記は実機能（反応タグ・満足度・好きTOP3・写真）と一致させる
- カード上部か下部に「今月 3回 / 累計 24回」のようなおでかけ数サマリーを小さく入れる
- **すべてダミーデータ**であること。実在の個人情報は使わず、「個人データを公開しているように見える」表現を避ける（例: フルネーム・実在しそうな顔写真風は不可。ひらがな名+絵文字アバターで）

### ヒーロー背景

- ベース: 現行の sky→cyan→emerald グラデーション維持
- 装飾レイヤーを「世界観が感じられる」レベルへ強化（ただし opacity 0.1〜0.15 で主役を邪魔しない）:
  - 大きめの点線ルートが左下→右上へ流れ、途中に地図ピン3つ
  - ピンの1つから小さな芽、1つにきらめき
  - 足あとペア2組（親の大きい足あと+子の小さい足あとを並べる = 親子感）
  - 右下にごく薄い等高線/地図グリッド風の曲線
- SVG はインライン1つにまとめ、viewBox 1200x600・preserveAspectRatio slice

## Task 2: 使い方セクション強化

現行の STEP カードをベースに以下を強化:

1. カードを `bg-white rounded-3xl shadow-md`（現 shadow-sm より立たせる）+ ホバーで `-translate-y-1`
2. アイコンを 64px 円形背景 + 現行カスタム SVG を一回り大きく
3. 各カードに**補足文**を1行追加（説明文の下に text-xs text-slate-400）:
   - STEP01 補足: 「1,000施設超 / 年齢・雨の日・無料で絞り込み」
   - STEP02 補足: 「ワンタップの反応タグで、入力は30秒」
   - STEP03 補足: 「タグが集計されて"好き"ランキングに」
4. セクション背景: 現行の薄い地図モチーフ維持 + `bg-gradient-to-b from-white to-slate-50`
5. カード間の点線コネクタは維持
