# 法務ページ（/privacy・/terms）可読性改善 仕様書

> 作成: 2026-06-12 / Claude Code PM（オーナー指示の転記）
> 前提: 35eabe3 で実装済みの両ページに対する UI/可読性の微調整。**本文の文面は変更しない**

## 修正内容

### 1. ヒーロー帯の縦余白をスマホのみ圧縮
- スマホでタイトル帯が大きく見えるため、**スマホのみ上下余白を縮小**（例: `py-16 → py-12` 程度。LegalDocument.tsx の `py-12 sm:py-16` を `py-8 sm:py-16` 等、見た目で判断してよい）
- 法務ページは装飾より本文の読み始めやすさを優先

### 2. 本文の読みやすさ微調整
- 箇条書き各項目の下マージンを少し広げる
- bullet と本文の距離を整える
- h2 / h3 の上下余白をできるだけ統一
- 詰まりすぎず読み疲れしないレイアウトに

### 3. 目次の追加（ページ内リンク付き）
ヒーロー直下または本文冒頭に簡易目次を追加。各 h2 セクションに id を付与してアンカーリンクにする。

- privacy: 事業者情報 / 本サービスの利用者について / 取得する情報 / 利用目的 / 匿名集計について / 写真の取り扱い / 第三者提供 / 委託先・外部サービス / Cookie 等の利用 / 保存期間 / データの削除 / 安全管理 / 改定
- terms: 適用 / アカウント / 禁止事項 / コンテンツの取り扱い / 施設情報について / サービスの変更・停止 / 免責 / 規約の改定 / 準拠法・管轄

### 4. モバイル本文の見やすさ改善
- スマホ幅での箇条書き・段落間隔・見出し下余白を微調整

## 変更しない点

- ヒーロー帯のブランドトーン・配色・世界観は現状維持
- 本文の文面は変更しない（UI/可読性の微調整のみ）

## 完了条件

- スマホでヒーロー帯がコンパクトになる
- /privacy /terms に目次（ページ内リンク付き）が追加される
- 箇条書き・段落余白が改善され、長文でも読みやすい
- PC1280 / モバイル375 両方で表示崩れなし（スクショ撮影）
