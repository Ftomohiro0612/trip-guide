# 施設紹介文と「楽しめそうなこと」の強化方針

> 作成: 2026-06-12 / Claude Code PM（オーナー指示 2026-06-12 反映）
> 最重要強化箇所: ①「この施設で楽しめそうなこと」②施設紹介文

## ① 「この施設で楽しめそうなこと」の強化

### 目指す姿

タグの列挙ではなく、**親が見た瞬間に「ここではこういう過ごし方ができそう」と想像できる体験リスト**。
情報量は多いほど良い。ただし**根拠のない想像で盛らない**。

### 形式

- チップ（現状）→ **チェックマーク付き箇条書き**に変更（読み物として目が流れる）
- 1項目 = 「動詞で終わる具体的な過ごし方」（例: 「長いすべり台で遊ぶ」「動物にえさやりをする」）
- 件数目安: 5〜12項目（施設の規模に応じて。最低3項目を下回る施設は紹介文増強を優先）
- 並び順: その施設の主役体験 → 副次体験 → 過ごし方系（「半日ゆっくり過ごす」等）

### 根拠ソースの優先順位（この順で採掘する）

1. **signature_experiences** — 最も具体的。ほぼそのまま体験文に変換可
2. **description / unique_selling_point** — 文中の事実（遊具名・体験名・併設施設）を分解
3. **公式サイト（url がある施設）** — 展開時に WebSearch/公式確認で補強（追加した体験は source_urls を更新）
4. **recommended_for_tags** — タグ→体験文の変換表（facility-experience-candidates.md）。ただし §B の照合ルールに従う
5. **category / indoor_outdoor / summer_water_play / target_age** — 「雨の日に室内で過ごす」「小さい子と一緒に遊ぶ」など横断的な過ごし方の根拠

### 禁止事項

- 上記ソースのどれにも根拠がない体験を追加しない（「〜もあるかも」は書かない）
- 料金・営業時間がからむ体験は断定しない（「カヌー体験（有料・開催日は公式確認）」のような注記はOK）
- water_play / pool の区別など既存タグルール（recommended_for_tags_rules.md）に反する変換をしない

## ② 施設紹介文の強化

### 目指す紹介文の要件

1. その施設の**主役となる遊び**が最初の1文で分かる
2. **どんな年齢の子**が楽しみやすいかが自然に入る
3. 屋内/屋外・雨の日・無料/有料などの特徴が**文中に自然に**織り込まれる
4. 親が**当日の過ごし方**（所要感・回り方・親の過ごし方）をイメージできる
5. 長さ目安: **150〜300字**（現状34字の施設も400字の施設もある → この帯に揃える）

### 文章構成テンプレート

```
[1文目] 主役の遊び＋施設の性格（〜できる、〜に特化した、など）
[2文目] 具体的な体験・設備の列挙（signature_experiences の主要素）
[3文目] 年齢適性＋親目線の情報（屋内外・雨・無料・親の休憩場所など）
[4文目(任意)] 過ごし方の提案（半日コース・併設施設との組み合わせ等）
```

### 書き換え時の禁止・削除事項

- **住所・料金・営業時間・閉店/移転は AI 推定で補完しない**（既存値の転記のみ可）
- 出典不明の評価表現を削除: 「星4.5」「星5.0」「口コミ高評価」等（現データに混入あり）
- 誇張表現（「絶対」「必ず」「日本一」※公式が謳う場合を除く）
- 既存 description にある事実の削除は慎重に（増強が基本、訂正は公式確認とセット）

### provenance との連動

- 既存フィールドの**再編集のみ**（事実の追加なし）→ data_quality_status は変更しない
- **公式サイトを見て事実を追加**した場合 → source_urls / source_checked_at を更新（confirmed 化は facility-provenance-schema.md の条件を満たす場合のみ）

## ③ 進め方

1. 代表5施設で試作（facility-page-v2-sample.md）→ オーナー確認
2. 文体・粒度を確定 → 体験候補の変換表を確定
3. 展開方法を別途PM判断: 優先順（アクセスが多い県・カテゴリから / url有り928件から等）と、バッチサイズ（50〜100件単位でレビュー可能な粒度）を決める
4. 表示テンプレート変更（チップ→箇条書き等）は試作確認後に実装タスク化

**全件一括の書き換えはしない**（881件事件・カンドゥー事件の教訓: レビュー可能な単位で段階適用）
