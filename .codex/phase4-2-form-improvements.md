# Phase 4-2: 記録フォーム改善

## 目的

反応タグ追加後もフォームを重くしすぎず、30秒記録の体験を維持する。

## 対象ファイル

- `app/mypage/visits/new/page.tsx`（記録フォーム）
- `app/mypage/visits/[id]/page.tsx`（詳細表示）

DBカラム削除は一切不要。UIのみ変更。

---

## 変更 1: 気温感を非表示

`temp_feeling` の入力UIをフォームから削除する。
DBカラムは残すのでサーバーへの送信も不要（送らないだけでよい）。
既存記録の詳細ページでも `temp_feeling` の表示行を削除する。

---

## 変更 2: 天気・混雑度の「覚えていない」を削除

### 天気（weather）

現行の選択肢から「覚えていない」を除外し、未選択（null / 空文字）を許容する。

残す選択肢例:
- 晴れ
- 曇り
- 雨
- 雪

### 混雑度（crowd_level）

同様に「覚えていない」を除外し、未選択を許容する。

残す選択肢例:
- 空いていた
- 普通
- 混んでいた

---

## 変更 3: 滞在時間を4択に整理

現行の細かい選択肢を廃止し、以下の4択に置き換える。
保存先は既存の `stay_duration_min`（INT）カラムをそのまま使う。

| ラベル     | 保存値（分） |
|-----------|------------|
| 〜1時間   | 60         |
| 2〜3時間  | 150        |
| 4〜5時間  | 270        |
| 6時間以上 | 360        |

- 未選択は `null` として許容
- 詳細ページでの表示: 保存値からラベルに逆引きして表示（例: `150 → "2〜3時間"`）
  - 逆引きマッピング: `{60: "〜1時間", 150: "2〜3時間", 270: "4〜5時間", 360: "6時間以上"}`
  - 上記以外の値（既存データ）はそのまま分数表示（例: `120分`）でよい

---

## 変更 4: 食事項目を整理

項目名を「食事」→「**ごはん・食事**」に変更。
保存先は既存の `food_rating` カラムをそのまま使う（値の意味は食事対応メモ）。

### 新しい選択肢

| ラベル         | 保存値          |
|--------------|----------------|
| 食事なし       | no_meal        |
| 施設内で食べた  | ate_inside     |
| 持参した       | brought_food   |
| 外で食べた     | ate_outside    |
| 食事で困った   | had_trouble    |

- 未選択（null）を許容
- 旧来の選択肢（`satisfied` / `unsatisfied` 等）は削除

### 詳細ページの表示

保存値からラベルに逆引きして表示。旧値（`satisfied` 等）が入っている既存記録はそのまま値を表示でよい。

---

## 変更 5: フォーム構成の整理

「もっと詳しく記録する」セクションの構成を以下に整理する。

### 必須・重要（常時表示）

1. 施設
2. 訪問日
3. 今回行った子ども
4. 子どもごとの満足度 + 何を楽しんでいた？（反応タグ）
5. また行きたい
6. 親の疲れ度

### 「もっと詳しく記録する」内（折りたたみ）

1. 滞在時間
2. 時間は足りたか
3. ごはん・食事
4. 天気
5. 混雑
6. 駐車場
7. メモ
