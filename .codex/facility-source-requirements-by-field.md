# 項目別 確定根拠要件（正本）

> 作成: 2026-06-11 / Claude Code PM
> 本表が項目別ルールの正本。facility-source-trust-levels.md は本表のマトリクス版（併読用）

## 凡例

- **公式必須**: 公式サイト・自治体・観光協会・信頼できる報道の一次情報がないと確定不可
- **補助情報可**: まとめサイト・口コミを参考にしてよい（確定時は「目安」前提）
- **AI要約可**: 確認済み情報の要約・分類・導出は AI が行ってよい
- **AI推定禁止**: 学習知識・推測での値の生成禁止

| 項目 | 要件 | 確定に必要なもの | 備考 |
|---|---|---|---|
| 施設名 | 公式必須 | 公式表記の確認 | メモ文字列混入禁止。通称はかっこ書き |
| **住所** | **公式必須・AI推定禁止** | source_urls（公式/自治体） | カンドゥー事件の対象 |
| **緯度経度** | 導出のみ | 確定済み住所 + Nominatim/Google + bbox 検証 | geocode_source 記録。住所未確定で座標確定禁止 |
| 営業時間 | 公式必須 | source_urls + source_checked_at | 鮮度が命。確認日のないものは「要確認」扱い |
| 定休日 | 公式必須 | 同上 | |
| 料金 | 公式必須 | 同上 | まとめサイトのみ→needs_web_check |
| 対象年齢 | 補助情報可 | 公式 or まとめサイト+「目安」表記 | |
| 駐車場 | 補助情報可 | 同上 | |
| 授乳室・オムツ替え | 公式必須（推奨） | 公式/自治体優先 | 子連れ判断に直結 |
| 雨の日対応 | AI要約可 | 確認済みの屋内外情報から導出 | enum: ◎/△/× のみ |
| 無料/有料 | 公式必須 | source_urls | enum: 無料/有料で始まる |
| カテゴリ | AI要約可 | 確認済み事実 | 分類自体は AI 可 |
| recommended_for_tags | AI要約可（条件付き） | description/公式説明内の根拠語彙 | rules.md の19キーのみ。根拠なし付与禁止 |
| description | AI要約可（条件付き） | 確認済み情報のみを素材に | **未確認情報の事実化禁止** |
| signature_experiences | AI要約可（条件付き） | 公式説明の要約 | |
| **閉店・移転** | **公式必須・AI推定禁止** | 公式/自治体/報道のURL | まとめサイトの閉店表記は「きっかけ」のみ |

## 確定できないときの行動

1. その項目を空欄/「要確認」にし、`data_quality_status` を `needs_web_check` に
2. source_notes に「料金は公式記載なし」等の理由を書く
3. **推測で埋めない・古い情報で埋めない・confirmed にしない**
