## 0. 現在地ボタンの仕上げ（オーナー追加 2026-06-13）

- **ラベルを「📍 現在地」にする**（「📍 現在地から探す」は不自然なので戻す。取得中は「📍 取得中...」）。アクセント色・先頭配置（id=1197の見た目）は**維持**。
- **現在地ボタンを全ての地図に出す**（施設一覧/カテゴリ/県/タグも）。実装は「ボタン・handleLocate・現在地マーカーを `storageKey` に依存させず**常時有効**」にする。**ページ側(呼び出し4カ所)は変更不要**。
- **表示状態の保存(sessionStorage)は従来どおり storageKey 配下（トップ・/map のみ）**。一覧/カテゴリ/県/タグでは保存しない（絞り込みで地図が動く前提・既存方針）。`FitBoundsOnChange` の挙動も従来どおり（storageKeyなし=always、あり=initial-only/never）。
- 現在地は**保存しない**（state のみ・既存どおり）。
- **操作の説明文を、わかりやすい場所に常時表示**する（オーナー追加）。**文言（確定）:「「📍 現在地」を押すと、現在地を表示できます。」**（「探せます」=並び替え/検索と誤読されるため不可。同義の「現在地を見るには「📍 現在地」を押してください。」でも可）。
  - 置き場所: 地図の近く（例: 地図のすぐ下の小さなキャプション行、または操作チップ群の近く）。**控えめなグレー小文字**で、ごちゃつかせない。地図オーバーレイ内でマーカーと重ならない位置。
  - 全地図（ボタンが出る全ページ）で表示。スマホでも短く収める（必要なら「📍現在地で近くから探せます」程度に簡略化可）。
  - 現在地取得の有無に関わらず常時表示（ボタンの使い方ガイドのため）。

## 背景

- 施設マーカーの Popup は `components/MapView.tsx` の `FacilityMarker` 内。現状: 県・カテゴリ／施設名／無料・雨・年齢バッジ／（ログイン時）訪問・行きたい状態／詳細リンク。
- 現在地（`currentLocation: [lat,lng] | null`）は MapView の state。📍現在地ボタン押下時のみ取得・**保存しない**（既存方針）。

## 1. 現在地から車での所要時間目安

- **経路APIは使わない**。現在地と施設の緯度経度から **haversine 直線距離(km)** を出し、**ざっくりの車移動目安をレンジ＋「目安」**で表示。
- `currentLocation` が null（未取得）のときは**この行を出さない**。勝手に位置情報を求めない（既存方針どおりボタン押下後のみ）。
- `currentLocation` を `FacilityMarker` に渡す（MapView → FacilityMarker に prop 追加）。現在地は保存しない。
- **表示はレンジ＋「目安」必須**（断定しない）。直線距離kmからバケットでラベル化（推奨表。Codexは妥当なら微調整可・ただし必ず「目安」を含めレンジ表現にする）:
  | 直線距離 | 表示ラベル |
  |---|---|
  | ≤ 5km | 車で約10〜20分目安 |
  | ≤ 10km | 車で約20〜35分目安 |
  | ≤ 18km | 車で約30〜45分目安 |
  | ≤ 30km | 車で約45分〜1時間目安 |
  | ≤ 45km | 車で約1〜1.5時間目安 |
  | ≤ 70km | 車で約1.5〜2時間目安 |
  | ≤ 100km | 車で約2〜3時間目安 |
  | > 100km | 車で約3時間以上目安 |
  - 先頭に「🚗 現在地から」を付ける等、所要時間と分かる短い表現に。1行で。
- 目的は厳密値でなく「今日行けそうか／遠出か」が分かること。

## 2. この施設でできそうなこと（things_to_do 短表示）

- `facility.things_to_do` を **最大2〜3件**だけ表示。見出し「この施設でできそうなこと」。
- 4件以上ある場合は先頭2〜3件のみ（残りは詳細ページで、の流れ）。
- `things_to_do` が**空/無しの施設はこの欄ごと非表示**。**fallback文の生成は禁止**（無理に作らない）。
- コンパクトに（短い箇条書き or 小チップ）。長文 things_to_do は1行に収め、はみ出しは省略（line-clamp等）。

## 3. ポップアップの見た目（コンパクト維持）

- 目標の情報量: 施設名／県・カテゴリ／（現在地取得済みなら）車の目安時間／できそうなこと2〜3件／詳細リンク。
- **既存の無料・雨・年齢バッジは維持してよい**（1行の小チップで邪魔にならない範囲）。ログイン時の訪問・行きたい状態も既存どおり。※ただし全体が縦に伸びすぎないこと。things_to_do は2〜3件上限で必ず抑える。
- スマホ(375)で**縦に長くなりすぎない**こと（行数を抑える・チップは短く・min-width は現状程度）。

## 触らない / 制約

- 経路API・Google Maps API は使わない（直線距離＋概算のみ）。
- 現在地は保存しない（state のみ・既存どおり）。
- データファイル（things_to_do の中身等）は変更しない。表示ロジックのみ。
- 地図の他機能（現在地ボタン・sessionStorage永続化・FitBounds・他4カ所の挙動）は変えない。
