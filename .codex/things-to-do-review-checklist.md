## バッチ全体

- [ ] 対象施設が eligibility 条件（confirmed / likely_ok / url有り）を満たしている
- [ ] 除外対象（needs_human_review / needs_web_check / url未入力 / exclude候補）が混入していない
  - **NHR は facilities_data.json の status では判定不可**。url-research-review-package.md の24件リスト（id 7,26,29,32,50,51,78,83,102,114,123,126,132,137,146,150,154,163,168,172,191,199,205,206）と必ず照合（batch-3 で id199 混入の教訓）
- [ ] **語尾分布チェック**: 同一語尾が全体の50%を超えていない。「〜時間を家族で楽しむ」等の水増し定型がない（batch-3 初版で118/222件の定型化が発生した教訓）
- [ ] 単語重複バグ（「じっくりじっくり」等）がない
- [ ] スキップ施設（根拠3件未満）に理由が記録されている
- [ ] **同一ブランド・同カテゴリ類似チェック（2026-06-13 オーナー追加）**: 同一ブランド・同カテゴリ施設で things_to_do が3項目以上同一/ほぼ同義になっていない（キドキド系・モーリーファンタジー系・namco系・屋内プレイランド系・科学館/博物館系は特に確認。差別化不能はスキップが正、固有の遊具名・展示名・体験名を優先）
- [ ] facilities_data.json が未変更（レビュー段階では生成物JSONのみ）

## 施設ごと（サンプリング: 初回バッチ全件、以降は各バッチ30%+境界例全件）

### 根拠
- [ ] 各項目に根拠フィールド（desc/sig/usp/タグ/横断ルール）が明記されている
- [ ] タグ単独採用△のもの（water_play/vehicle/experience/character/food）が desc/sig 照合済み
- [ ] 根拠のない「盛り」項目がない（〜もあるかも・推定遊具名）

### 表現
- [ ] 動詞止め・親が当日を想像できる粒度
- [ ] 固有名詞の誤字・施設取り違えがない（特にチェーン店・同名施設）
- [ ] 水遊び/プールの区別が正しい（poolタグなしに「プールで泳ぐ」がない）
- [ ] 「写真を撮る」が写真目的の自然な施設に限定されている
- [ ] 「半日/1日たっぷり」が大型施設に限定されている
- [ ] food が体験寄り表現（収穫・料理体験）になっている
- [ ] 持込可否（お弁当）・ベビーカー文言が公式根拠なしで入っていない
- [ ] 料金がからむ体験に「（有料・公式サイトで確認）」等の注記がある
- [ ] 出典不明の評価表現（星・口コミ）が混入していない

### 構成
- [ ] 3〜12項目（3件未満は付与しない）
- [ ] 並びが 主役→副次→過ごし方系
- [ ] 重複・ほぼ同義の項目がない
- [ ] **1項目が長すぎない（目安20〜35文字は上限側。下限はない — 9〜15字が標準。長い場合は括弧注記で短縮）**
- [ ] **字数合わせの詰め物がない（2026-06-13 batch-4 の教訓）**: 「じっくり」「親子一緒に」「細かな」「迫力ある」等の修飾語が高頻度（目安: 同一修飾語が全体の5%超）で挿入されていない。仕様に字数下限を書くと padding が誘発されるため、下限指定は禁止

### 過度な一般化の禁止（2026-06-12 オーナー追加）
- [ ] どの公園にも「芝生で走り回る」と書いていない（広場の根拠がある施設のみ）
- [ ] どの屋内施設にも「雨の日に室内で過ごす」と書いていない（rain◎×屋内系の条件充足のみ）
- [ ] どの自然施設にも「写真を撮る」と書いていない（写真目的が自然な施設のみ）
- [ ] 小規模施設に「半日〜1日たっぷり遊ぶ」と書いていない
- [ ] 公式確認なしに「お弁当」「ベビーカー」「食事」「駐車場」を書いていない
- [ ] **量産臭がない**: 同カテゴリ施設で似た文言が連発していない。施設固有の遊具名・展示名・体験名がある場合はそちらを優先

### 注記・断定回避（2026-06-12 オーナー追加）
- [ ] 季節限定・有料・開催日限定・予約制の可能性がある体験に、必要に応じ「公式サイトで確認」注記がある
- [ ] 公式根拠なしに年齢を断定していない（「2歳から可能」✗ →「小さい子も一緒に楽しみやすい」○）
